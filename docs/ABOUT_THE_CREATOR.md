His public project portfolio shows practical exploration across Python software development, AI/ML, computer vision, OCR, local-first assistants, backend engineering, cybersecurity intelligence and workflow automation.

- **FlowForge-AI** — modular n8n automation library with reusable business workflows, setup guides and validation.
- **ILLI AI** — local-first Windows assistant exploring voice interaction and desktop automation.
- **Phishing URL Detector** — URL-text classification project with documented evaluation metrics and automated tests.
- **GYRUS** — voice-oriented assistant project with media controls, scheduling and desktop dashboard features.
- **AutoLoom AI** — a documented library of 100 AI-assisted automation workflows with setup guides and validation.
- **CIVID** — a source-verified civilian-impact research dataset with provenance, citation and human-review requirements.

- **Python Core and Advanced Handbook** — a structured Python learning resource based on notebooks, scripts and practical notes.
